# سُفرة — قناة الطلب المباشر (الباقة الأولى)

منصة تخلي المطعم أو الكافيه يستقبل طلبات مباشرة من زبائنه **بدون عمولة**. الزبون يطلب من رابط أو QR بدون ما ينزّل تطبيق، والطلب يوصل للوحة المطعم لحظياً، والمطعم يرجّع الزبون بنقاط الولاء وحملات الواتساب.

## التشغيل

يحتاج **Node.js 22.13 أو أحدث**، وما يحتاج أي مكتبات خارجية (`npm install` غير مطلوب).

```bash
npm start
```

بعدها افتح `http://localhost:3000`.

| الصفحة | الرابط |
|---|---|
| الصفحة الرئيسية للمنصة | `/` |
| متجر تجريبي (مطعم) | `/r/beit-baghdad` |
| متجر تجريبي (كافيه) | `/r/rasif` |
| طلب من طاولة | `/r/beit-baghdad?t=5` |
| لوحة المطعم | `/admin` |

### الحسابات التجريبية (للوحة المطعم)
| المتجر | رقم الهاتف | كلمة المرور |
|---|---|---|
| مطعم بيت بغداد | 07700000001 | demo1234 |
| قهوة الرصيف | 07700000002 | demo1234 |

أو اضغط "جرّب بحساب تجريبي" بصفحة الدخول.

لإعادة البيانات التجريبية من الصفر: `npm run reset`.

## النسخة الحقيقية على Cloudflare (مجانية)

**الرابط:** https://sufra.sufra-order.workers.dev

هذي هي النسخة اللي تنستخدم للتجربة الفعلية وية المطاعم. الطلب ينتقل من تلفون الزبون لتلفون المطعم، والبيانات تنحفظ بقاعدة Cloudflare D1.
- `worker/index.js`: الخادم (نفس منطق `server.js`)
- `worker/schema.sql`: مخطط قاعدة البيانات
- `worker/seed.sql`: المتجرين التجريبيين
- `wrangler.jsonc`: الإعدادات

```bash
npx wrangler deploy
```
يرفع أي تعديل جديد.

```bash
npx wrangler d1 execute sufra --remote --command "SELECT COUNT(*) FROM orders"
```
يستعلم من قاعدة البيانات.

### إشعارات تيليگرام
1. بتيليگرام افتح **@BotFather**، واكتب `/newbot`، واختار اسم ويوزر للبوت (لازم ينتهي بـ `bot`).
2. شغّل ملف **`ربط-تيليگرام.bat`** والصق التوكن اللي أعطاك ياه BotFather. التوكن ينحفظ مشفّر على Cloudflare.
3. حط يوزر البوت بـ `TELEGRAM_BOT_USERNAME` داخل `wrangler.jsonc`، وبعدها نفّذ `npx wrangler deploy`.
4. كل مطعم يربط حسابه من: لوحة المطعم ← الإعدادات ← "ربط تيليگرام".

## نسخة العرض على GitHub Pages (تطبيق موبايل)

مجلد `docs/` فيه نسخة تشتغل بالكامل داخل المتصفح، بدون سيرفر. فيها خادم وهمي (`public/demo/mock.js`) يطبّق نفس منطق السيرفر، ويحفظ البيانات على الجهاز (IndexedDB)، ويبث التحديثات بين التبويبات. مخصصة للعرض على أصحاب المطاعم:
- تتنصّب كتطبيق على الشاشة الرئيسية: Android من زر "ثبّت"، وiPhone من مشاركة ← إضافة إلى الشاشة الرئيسية
- زر **"محاكاة طلب جديد"** بلوحة المطعم يجيب طلب وهمي مع التنبيه الصوتي
- زر **"إعادة ضبط"** يرجّع البيانات التجريبية للبداية

لإعادة بنائها بعد أي تعديل:
```bash
npm run build:pages
```

> نسخة العرض تحفظ البيانات على نفس الجهاز، فالطلب ما ينتقل من تلفون الزبون لتلفون المطعم. للتجربة الفعلية وية مطعم، شغّل `server.js` على استضافة حقيقية.

## شنو يسوي

**للزبون (صفحة المتجر):**
- منيو أونلاين بالأقسام، مع بحث وقسم "الأكثر طلباً"
- خيارات لكل صنف (الحجم، الحليب، الإضافات) وكل خيار بسعره، مع ملاحظة للمطبخ
- توصيل حسب المنطقة وأجرتها، أو استلام، أو طلب من الطاولة عبر QR
- إرسال الموقع الحالي (اختياري)، وكوبونات خصم
- نقاط ولاء تنعرض حسب رقم الهاتف وتنستخدم كخصم
- تتبّع الطلب لحظياً بالمراحل والوقت المتوقع
- "طلباتي" و"اطلب نفس الطلب مرة ثانية"

**لصاحب المطعم (اللوحة):**
- **الطلبات:** لوحة حيّة بثلاث مراحل، مع تنبيه صوتي متكرر وإشعار. قبول الطلب مع تحديد وقت التجهيز، أو رفضه مع سبب يظهر للزبون. فيها تمييز "زبون جديد" مقابل "الطلب رقم 5"، وأزرار اتصال وواتساب، ورابط الخريطة، وطباعة تذكرة المطبخ
- **إيقاف مؤقت للاستقبال** بضغطة، وأوقات عمل تفهم الدوام اللي يعبر منتصف الليل
- **المنيو:** أقسام وأصناف وصور (تنضغط تلقائياً) وخيارات، مع زر "نفد" فوري
- **الزبائن:** شرائح (دائمين، منقطعين +30 يوم، عندهم مكافأة، جدد) وحملة واتساب برسالة مخصصة لكل زبون
- **الكوبونات:** نسبة أو مبلغ ثابت، مع حد أدنى وعدد استخدامات وتاريخ انتهاء
- **التسويق:** رابط المتجر، وQR قابل للتنزيل، وبطاقات للأكياس، وQR مرقّم لكل طاولة جاهز للطباعة
- **الإحصائيات:** العمولة الموفّرة، والإيرادات، ونسبة الزبائن العائدين، وأوقات الذروة، وأعلى الأصناف
- **الإعدادات:** الهوية واللون والشعار والغلاف، ومناطق التوصيل، وقواعد النقاط

## التقنية
- `server.js`: خادم Node.js بدون مكتبات، وقاعدة بيانات SQLite المدمجة (`node:sqlite`)، وتحديثات فورية عبر Server-Sent Events
- `seed.js`: البيانات التجريبية
- `public/store`: صفحة الزبون
- `public/admin`: لوحة المطعم
- `public/index.html`: الصفحة الرئيسية
- البيانات تنحفظ في `data/` (قاعدة البيانات والصور المرفوعة)

**الحماية الموجودة:**
- الأسعار تنحسب بالخادم، وما ينوثق بأي سعر يجي من المتصفح
- كل مطعم معزول عن غيره
- كلمات المرور مشفّرة بـ scrypt، والجلسات بكوكي HttpOnly
- حد للمحاولات على الدخول والطلبات والكوبونات
- رابط تتبّع الطلب محمي برمز سري

## قبل الإطلاق الفعلي (المرحلة الجاية)
- استضافة على سيرفر مع HTTPS ودومين، ونسخ احتياطي لمجلد `data/`
- تأكيد رقم الزبون برمز OTP (واتساب أو SMS) قبل استخدام النقاط
- الدفع الإلكتروني (FIB، زين كاش، Qi)
- إرسال حملات الواتساب تلقائياً عبر WhatsApp Business API
- دعم اللغة الكردية
- ربط بـ "سُفرة" لإدارة المطبخ والمخزون (الباقة الثالثة)
